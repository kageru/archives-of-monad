# Archives of Monad
A rust application that parses data from the [FoundryVTT Pathfinder 2e game system](https://gitlab.com/hooking/foundry-vtt---pathfinder-2e/) and generates static html pages from it.
I used to maintain this, but the foundry team kept making breaking changes to the JSON schema (which of course they have the right to), so I stopped at some point in 2023. As of 2026, I’m letting an LLM update the json schema whenever something changes.

The latest version is always deployed at [prd.kageru.moe](https://prd.kageru.moe/).

This repo builds on the latest stable Rust, but there is no guarantee it will stay that way.
